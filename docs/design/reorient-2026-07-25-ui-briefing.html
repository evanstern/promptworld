Verdict

All four evaluations converged: the shipped TUI already implements the surveyed corpus's watching craft — the digest grammar is Cogmind's log discipline fused with RimWorld's severity language, the villager drill-down is the Smallville inspector chain, the ? overlay is Cogmind's tiered context help. What was missing was every game surface:

  • The central verb lived in a one-line, tail-truncating minibuffer feeding a telemetry-crowded tab.
  • The curriculum ladder — the pivot itself — rendered as one header segment plus feed lines that scroll away at 16×; the ladder's front door was a CLI command outside the game.
  • The scenario run (the ratified v1 game) had no designed screen: no rubric, no briefing, no score surface — and the narrator's ~2 chapters/game-day cadence means short runs could produce zero chronicle entries.
  • The page-by-page design reference had rotted ~6 specs behind shipped reality, so "build from the design doc" was already false.

No big refactor. Every adopted surface is additive on the existing five-region anatomy and the replica machinery — the Dwarf Fortress Premium lesson (redesigns that orphan the old layout's logic draw their own criticism) is the standing guardrail.

The eight decisions

  1. Headline direction: the Staged Cockpit.

    Guardian console page + systems-tab telemetry split, map-legibility wins (jump-to-source, villager strip, overlays), and stage-shaped progressive layout defaults.

  2. Charter authoring: in-TUI read, $EDITOR write.

    The console shows charter/skills with binding status and honest lock notices; authoring hands off to the editor — no in-TUI text editor.

  3. Stage shapes layout defaults only.

    Everything reachable at every stage and via ?; pre-ladder worlds get everything; capability locks stay angel-only (spec 046 doctrine untouched).

  4. docs/design/tui v2 is the living authority, gated.

    Pages/panels/overlays/patterns + uniform control tables; verified_against pins + check script enforce same-PR amendments.

  5. Lessons get a dedicated row.

    One active lesson, ≤2 lines, dwells until done, points at a key/tab; default-on at stages 1–2, badge+overlay elsewhere.

  6. Both big moments seize the screen.

    Stage-unlock ceremony and run-end postmortem take over immediately (operator chose salience over the never-interrupt rule); both dismissable and replayable from pull surfaces.

  7. Guardian strip above the minibuffer.

    Charge, regen, watches, faith — the action budget pairs with the input line so the minibuffer reads as THE verb.

  8. Input parity ratified.

    Every action keyboard AND mouse, keyboard primary; control tables gain a mouse column so a parity sweep test can exist.

Plus 13 lead-adopted defaults (D1–D13) — terminal-first rendering with the linear-stream accessibility floor, skin-tokens-before-literals, per-exercise forecast/fog, per-user lesson state, player-authorship unlock voice, rubric-first fork duels, and more — recorded in full in the synthesis.

How a tiny AI village turns "something happened" into a fact it can remember forever.

A Village That Runs Itself

Picture a lighthouse keeper's logbook. Nothing officially happened at the lighthouse unless it was written down — and every entry says exactly where, when, and why. promptworld runs on that same idea, except the lighthouse is a tiny village and the keeper never sleeps.

🗺️
A grid the villagers live on

The whole world is a 64×64 grid of tiles — a small town's worth of ground.

🧍
Villagers with real needs

Each villager is a small AI agent with hunger, warmth, and rest to manage, a body that can get hurt, and a private memory only she can see.

⏱️
A clock that never stops

promptworld is an always-on simulation daemon: it advances one tick — one game‑second — at a time, forever.

The promise of this course

By the end, you'll know exactly how these AI villagers remember — and how to design memory into your own AI projects on purpose, instead of leaving it to chance.

Now watch one villager for thirty seconds. She's hunting. Her spear snaps on its very last use. A minute later she's telling a friend about it. That ordinary little moment is about to become a permanent, structured fact — with a number attached to how much it mattered.

Not All Moments Are Equal

A newsroom editor doesn't give a lost umbrella the same headline as a fire downtown — every story gets ranked by how big a deal it is. promptworld ranks memories the same way, with a plain constant from 1 to 10.

CODE 

const (
salTalk           = 3
salHunt           = 4
salFire           = 5
salShelter        = 6
salStarvingForage = 5
salColdNight      = 5
salNearDeath      = 9
salWitnessDeath   = 10
)
PLAIN ENGLISH

Start a list of named numbers — so the code can say "this kind of moment" instead of a bare digit nobody remembers the meaning of.

Having a chat: worth 3 out of 10. Routine, easily forgotten.

Going hunting: worth 4 — a little more memorable than small talk.

Building a fire: worth 5 — a small survival win.

Building shelter: worth 6 — a bigger survival win than a fire.

Foraging for food while starving: worth 5 — as memorable as building a fire.

Surviving a freezing night: worth 5 as well.

Nearly dying: worth 9 out of 10 — one of the most formative things that can happen to her.

Watching someone else die: the maximum, 10 — the single most formative memory possible.

End of the list.

Notice the pattern: routine moments score low, survival wins score in the middle, and life‑or‑death moments top the scale.

Captured the Instant It Happens

A Polaroid camera doesn't ask you to describe the room afterward — it captures where you were and what the light looked like the second you press the shutter. The function that creates a memory works the same way.

CODE 

func situatedMemoryEvent(tick int64, agent, salience int, where *MemoryPlace, why, origin, format string, args ...any) store.Event {
return store.Event{
Tick: tick, Type: "agent.memory_added",
Payload: mustPayload(MemoryAddedPayload{
Agent: agent, Text: situateText(fmt.Sprintf(format, args...), where, why),
Salience: salience, Subject: -1, Where: where, Why: why, Origin: origin,
}),
}
}
PLAIN ENGLISH

A recipe for making one memory. It needs: the moment, who felt it, how important it was, where, why, and how the sentence should read.

Package all of that up into one event — one write to the village's official history.

Stamp it with the exact tick it happened, and label it as a brand-new memory.

Who it belongs to, and the memory's sentence — with the place and reason already woven in.

The importance score, the place, the reason, and whether she did it, saw it, or heard about it.

Finish packaging the event.

Hand the finished memory off to be permanently recorded.

💡
Key insight

Where and why are stamped at the moment the event happens, never reconstructed later. That context is cheap to grab right now and nearly impossible to get right after the fact — a pattern worth stealing for any AI project you build.

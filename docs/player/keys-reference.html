Keys reference

Every key promptworld ui responds to, grouped by what's on screen when you press it. Pure controls — for what any of this is actually showing you, see what do all those things on screen mean instead.

Normal view (nothing focused — the default)

KeyAction
1Return to the split view (from a solo tab)
2 / 3 / 4Switch to the chronicle / Metatron / villagers tab — the same key again fills the screen with that tab; press it a third time (or 1) to go back
mStart typing to Metatron
spacePause / resume the world
[ / ]Speed down / up
← ↑ ↓ →Pan the map
cRecenter the map on your villagers
rChronicle: toggle narrated ↔ raw feed
a / tChronicle: filter by villager / storyline
qQuit — just detaches, the world keeps running
ctrl+cQuit, from any mode

Talking to Metatron (after pressing m)

KeyAction
Printable keys, spaceType into your message
backspaceDelete
↑ / ↓Step through messages you've sent before
⏎Send (an empty box just stops typing instead)
escStop typing without sending
ctrl+cQuit

Looking back through the feed (pause the world first)

All of the normal-view keys above still work here too — these are additions, not replacements.

KeyAction
j / kSelect the next / previous entry
g / GJump to the first / last entry
J / KScroll a long entry's detail
⏎Reserved for a future action — does nothing yet
spaceResume (also clears your selection)

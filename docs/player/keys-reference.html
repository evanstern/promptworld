Keys reference

Every key promptworld ui responds to, grouped by what's on screen when you press it. Pure controls — for what any of this is actually showing you, see what do all those things on screen mean instead.

One thing to know up front: the whole game is playable from the keyboard alone — every key below reaches everything, and that stays true no matter what. Mouse support is a separate, additive convenience layered on top; so far it covers exactly one action, the chronicle jump described below, and everywhere else a click simply does nothing.

The guardian console (after pressing G)

A full-screen page for the conversation — each turn rendered as its own labeled block, a charter/skills panel beside it, and a hook into your own text editor. Most other keys (space, [ / ], 2-5, pan, a / t, r, q) still work exactly as in the normal view underneath.

KeyAction
G / 1 / escClose, back to whatever was open before
mStart typing to the guardian (the same message box as everywhere else)
eOpen charter.md in your own text editor (your $EDITOR); on return, the console confirms "charter changed — next turn binds it"
J / KScroll toward the latest turn / scroll back toward older ones

Looking back through the feed (pause the world first)

All of the normal-view keys above still work here too — these are additions, not replacements.

KeyAction

When the run ends

Two full-screen moments take over the keyboard entirely — while either is on screen, every other key does nothing (except ctrl+c, which always quits).

A stage-unlock ceremony appears the moment you earn a new stage: a short celebration naming what you just proved and what it unlocks.

The postmortem appears once, the moment a run ends (your last villager has died) — a full-screen summary of how the run went. You can also reopen it any time afterward with p from the normal view.

KeyCeremonyPostmortem
escDismiss (returns to whatever was beneath — nothing else is force-closed)Dismiss — reopen later with p
qQuit/detach — the world keeps running Quit/detach — plainly, since the run itself has actually ended
everything else, including ?Does nothing — the takeover keeps the screen until you press esc or q

Missed or dismissed a ceremony? Nothing is lost — the help overlay's ceremonies section (below) keeps a permanent replay of every stage you've ever unlocked in that world.

The help overlay (after pressing ?)

The overlay shows this same information in-game — the keys for whatever screen you were just on, a tour of everything on screen, every lesson the game can teach you (including ones you dismissed with x — nothing is ever lost), a permanent replay of every stage-unlock ceremony you've earned in this world, and a page on the guardian itself: your current stage, what it teaches, every verb it grants you, and one example ask per verb. It never touches the world: opening it doesn't pause anything, and closing it puts you back exactly where you were.

KeyAction
? or escClose the overlay
tab / shift+tabCycle its five sections: keys → the screen → lessons → ceremonies → the guardian
tKeys section: switch between the basic and advanced key lists
n / pKeys section: page through every mode's key list (including the guardian-typing keys, which ? can't reach directly)
J / KScroll a long page

The guardian section always shows something useful, even on a brand-new world or with no AI configured at all — it reads only your world's stage, never anything the guardian says.

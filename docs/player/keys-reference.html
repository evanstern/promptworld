Keys reference

Every key promptworld ui responds to, grouped by what's on screen when you press it. Pure controls — for what any of this is actually showing you, see what do all those things on screen mean instead.

One thing to know up front: the whole game is playable from the keyboard alone. There's no mouse support yet — these keys are the complete set of controls, not a shortcut list.

Normal view (nothing focused — the default)

KeyAction
1Return to the split view (from a solo tab)
2 / 3 / 4Switch to the chronicle / Metatron / villagers tab — the same key again fills the screen with that tab; press it a third time (or 1) to go back
mStart typing to Metatron
spacePause / resume the world
[ / ]Speed down / up
← ↑ ↓ →Pan the map
cRecenter the map on your villagers
rChronicle: toggle narrated ↔ raw feed

qQuit — just detaches, the world keeps running
ctrl+cQuit, from any mode

The help overlay (after pressing ?)

The overlay shows this same information in-game — the keys for whatever screen you were just on, a tour of everything on screen, and (in the future) lessons the game has shown you. It never touches the world: opening it doesn't pause anything, and closing it puts you back exactly where you were.

KeyAction
? or escClose the overlay
tab / shift+tabCycle its three sections: keys → the screen → lessons
tKeys section: switch between the basic and advanced key lists
n / pKeys section: page through every mode's key list (including the Metatron-typing keys, which ? can't reach directly)
J / KScroll a long page

# Contract: grounded feedback layer (spec 063)

## §1 Explain (pull)

- Read-only registry tool; expressive-class, empty events; grant-gated
  through the standard three layers; structurally absent when ungranted.
- Result = deterministic fact sheet (data-model): registry/doctrine ground
  truth, scoped to the world's effective grant + stage ceiling; ungranted
  cataloged tools are named as existing-but-ungranted; unknown topics
  return the topic catalog.
- Zero cost: no charge, no mediated-act consumption (read-only tools don't
  count as the turn's one act), no world events beyond standard tool-call
  telemetry, no faith (obligation recorded for TASK-118).
- Repeatable: identical (state, topic) → byte-identical answer.

## §2 Tutor guide

- Compiled-in, tutor-preset-scoped, editable-zone composition (after
  charter/voice/SOULs, before skills/frame); fixed frame last on every
  path; non-tutor composition byte-identical to pre-feature.
- Content contract: orient; mechanics numbers via explain only; UI
  questions point at `?`/keys; never invent mechanics.

## §3 Report card (push)

- Produced ONLY at stopping points: run end · exercise resolution · pause
  episode (debounced, activity-gated). Never a takeover; never mid-run;
  console badge between (existing pattern).
- Composition: rubric checklist (TASK-127's shared renderer, when rubric
  data exists) + attribution note (cheap chain), clearly separate blocks,
  checklist authoritative.
- Grading inputs are EXACTLY the shared data source: recorded tool-call
  verdict trail, rubric evidence, charter-revision fingerprints + text,
  explain-class fact sheets. Every citation names a recorded event seq;
  the graded charter fingerprint is stated.
- Degradation: chain unavailable → deterministic parts only, silently.
- Stored once (pre-end: `guardian.report_card` prose event; run end: the
  existing epilogue channel); re-opened cards re-read the stored note.
- Surfaces: console card seam (spec 053) + postmortem (spec 056). D1: the
  stored note is visible on the raw feed/morgue like every prose event.

## §4 The `?` guardian section (D9)

Static-per-stage, model-free, byte-identical per identical status: stage
identity (skin-resolved) · effective granted verbs · one example ask per
verb (skin-token nouns). A deliberate spec-045 content-contract amendment.

## §5 Non-goals

No initiative-frame changes; no player-skill mechanics changes; no new
takeovers; no live re-grading; no faith mechanics (TASK-118); no rubric
terms over tutor telemetry (sweep-enforced).

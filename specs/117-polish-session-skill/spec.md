This directory exists on `main` to claim spec number 117 for TASK-198 before any
implementation commit, per the claim-before-work protocol (spec 065) and the stub-first
rule (TASK-195). `spec-bridge`'s gate derives a linked task's provable status by reading
`specs/NNN-*` off the filesystem at the repository root, so a spec that lives only on a
branch is invisible to it.

The stub is claimed up front here for the reason the skill itself will teach: a session that
might escalate claims its number before content lands, rather than discovering mid-stream
that it needed one.
